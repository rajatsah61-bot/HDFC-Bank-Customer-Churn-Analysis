# HDFC Bank Customer Churn Analysis

## 📌 Project Overview

This project analyzes customer data to understand customer behavior, churn patterns, account balances, and demographic trends. The analysis was performed using Python, SQL, and Jupyter Notebook.

---

## 🎯 Objectives

- Clean and preprocess banking data
- Analyze customer demographics
- Identify churn patterns
- Visualize important business insights
- Perform SQL-based analysis

---

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- MySQL
- Jupyter Notebook
